# Security Policy

Thanks for helping keep smistudy and its users safe.

## Supported versions

Only the latest version, the `main` branch deployed at [smistudy.ca](https://smistudy.ca), receives security fixes.

## Reporting a vulnerability

**Please don't report security problems in public issues, pull requests or discussions.**

Report them privately by either:

- using GitHub's **[private vulnerability reporting](../../security/advisories/new)** on this repository, or
- emailing **[privacy@smistudy.ca](mailto:privacy@smistudy.ca)** with "Security" in the subject.

Please include:

- what the problem is and what an attacker could do with it,
- steps to reproduce, or a proof of concept,
- the affected page, API endpoint or file, if you know it.

## What to expect

- An acknowledgement within **3 days**.
- An initial assessment within **7 days**, and regular updates until it's resolved.
- Credit in the fix's pull request, if you'd like it.
- If the issue affected users' personal information, we'll notify them and the Privacy Commissioner where the law requires (see the [Privacy Policy](https://smistudy.ca/privacy)).

## Good-faith research

We welcome research that:

- only uses accounts you own, or that you've been given permission to test,
- never accesses, changes or deletes other people's data. If you hit someone else's data by accident, stop, don't keep it, and tell us.
- doesn't degrade the service for others (no denial-of-service, spam or heavy automated scanning),
- gives us a reasonable chance to fix the problem before you disclose it publicly.

We won't pursue or support legal action against research done in good faith under these guidelines.

## Out of scope

- Reports from automated scanners without a demonstrated impact
- Missing security headers or best practices with no practical exploit
- Rate limits that can be exceeded only by spending significant resources
- Social engineering, or physical attacks
- Problems in third-party services (Cloudflare, Google, Resend, OVHcloud) — please report those to the provider
